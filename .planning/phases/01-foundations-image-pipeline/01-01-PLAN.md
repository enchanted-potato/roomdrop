<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → developer machine | Locked deps installed via `pnpm install`; supply-chain risk if a package is compromised |
| User → browser (file picker) | User selects a file via `<input type=file>`; in Plan 01 the file is NOT decoded or persisted (no attack surface yet — pipeline lands in Plan 03/04) |
| Browser → IndexedDB | Local-origin store; same-origin policy is the only access control |
| Browser → fonts.googleapis.com / fonts.gstatic.com | Plan 02 will add Google Fonts CSS links; Plan 01 has no third-party runtime requests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-SC | Tampering | `pnpm install` of 17 packages | mitigate | All 17 packages slopcheck-verified [OK] on 2026-06-25 per RESEARCH §"Package Legitimacy Audit"; commit `pnpm-lock.yaml` (D-10) to pin exact versions; no `postinstall` scripts on `exifr`/`idb-keyval`/`zustand` (verified). `vitest` flagged [SUS] is a known typosquat false positive (official Vite team runner) — pre-approved by audit, no human checkpoint required. |
| T-01-01-01 | Information Disclosure | Footer link target | accept | `REPO_URL` placeholder until repo published (RESEARCH Open Question #2). No PII; link is publicly known once shipped. |
| T-01-01-02 | Tampering | Branded `BlobId` type | mitigate | `BlobId` template-literal type prevents Plan 03+ from passing arbitrary strings to IDB helpers, reducing the chance of key collisions across namespaces. |
| T-01-01-03 | Denial of Service | `<input type=file>` accepting any file in Plan 01 | accept | Plan 01 only opens the picker; the selected file is never read or processed. Real DoS surface (oversized image / malicious EXIF) is gated by HEIC sniff + 2048-px cap in Plan 03 (T-01-03-*). |
| T-01-01-04 | Repudiation | LICENSE file at repo root | mitigate | AGPL-3.0 text copied verbatim from `gnu.org/licenses/agpl-3.0.txt`; footer link discloses license + source repo per Section 13 obligation. |
| T-01-01-05 | Configuration | Vite `base: './'` | mitigate | D-14 requires portable static bundle; verified by `grep "./assets/" dist/index.html` in Task 1 verify command. |
</threat_model>
